# SON Media

Website HTML/CSS/JS được bóc tách trực tiếp từ frame Figma SON Media. Mỗi section, card, menu, nút và popup là thành phần HTML riêng; toàn bộ ảnh và SVG được lưu trong repository.

## Chạy local

Mở `index.html` trong trình duyệt. Không cần cài đặt dependency hoặc chạy server.

Toàn bộ asset thiết kế nằm trong `assets/figma/home/`; dự án không sử dụng URL ảnh bên ngoài. File `export.png` là ảnh đối chiếu nguyên frame và không được dùng để hiển thị website.
